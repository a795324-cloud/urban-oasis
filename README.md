## 本機預覽
直接以瀏覽器開啟 `index.html` 即可預覽。

## 部署方式
1. 將本資料夾中的所有檔案上傳至 GitHub repository。
2. 在 Vercel 選擇 Import Project，連接該 GitHub repository。
3. Framework Preset 選擇 Other，Build Command 與 Output Directory 留空或使用預設值。
4. 部署完成後，使用 Vercel 提供的網址檢查桌面與手機畫面。

## 作業交付連結（部署後補上）
1. Prompt 說明 GitHub 連結：請貼上 `PROMPT.md` 的 GitHub 檔案網址。
2. InfinityFree 個人網址：請貼上自己的首頁網址（若老師要求此項）。
3. Vercel 部署網址：請貼上 Vercel 專案部署完成後的網址。

## 圖片說明
目前沒有實地拍攝照片，因此使用原創 SVG 情境插畫呈現場景意象；插畫並非帝國糖廠實景照片。若日後取得實際照片，可替換 `images/` 中的素材並更新頁面。
